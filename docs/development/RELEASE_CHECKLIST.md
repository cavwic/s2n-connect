# Release checklist

- [ ] Build passes on win-x64, win-arm64, osx-x64, osx-arm64, linux-x64 and linux-arm64.
- [ ] Test sing-box install into a path containing spaces and non-ASCII characters.
- [ ] Test encrypted and unencrypted OpenSSH private keys.
- [ ] Test first-use SSH host fingerprint prompt and mismatch rejection.
- [ ] Test Ubuntu 24.04 and Debian VPS deployment.
- [ ] Test Windows UAC, macOS administrator prompt and Linux polkit paths.
- [ ] Confirm LAN/NAS traffic remains direct.
- [ ] Confirm process rules and domain rules operate independently.
- [ ] Confirm Stop and Exit remove the TUN route and restore DNS.
- [ ] Verify UDP 443 with real QUIC traffic; wrong certificate, TLS name and password must fail without direct fallback.
- [ ] Run three first-start Windows TUN cycles and cancellation cleanup while preserving an unrelated core and adapter.
- [ ] Verify imported legacy VLESS and Hysteria2 profiles, atomic credential storage, and portable iOS certificate trust.
- [ ] Sign Windows artifacts.
- [ ] Sign and notarize macOS artifacts.
- [ ] Publish SHA-256 and artifact attestations.
- [ ] Review third-party notices and licenses.
- [ ] Android lint, JVM profile/config tests and debug APK build pass.
- [ ] Android emulator imports profiles, switches language/theme and parses production core configurations.
- [ ] Android emulator authorizes, establishes and stops a direct-only synthetic TUN.
- [ ] Release APK contains ARM64 and x86_64 native libraries and uses the expected persistent certificate.
- [ ] On a physical Android device, verify a real VPS connection, proxy access, LAN access, network switching and Stop cleanup.
- [ ] Publish all seven packages, their individual SHA-256 files, and combined `SHA256SUMS`.
